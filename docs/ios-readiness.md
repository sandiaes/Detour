# iPhone readiness (the Mac route, ADR 008)

Detour will be built for the owner's iPhone on the owner's Mac and installed over a cable, never
through the App Store or TestFlight (ADR 008, decision 3). This is Phase 11 (Prompt 13); nothing for
iOS has been built or tried yet. This page records where the code stands, so Phase 11 is a build and
test task rather than a rewrite. Written in Phase 9 (2026-11-15).

## 1. What is already shared

- **All planning, search, travel times, names and photos are on the backend**, which an iPhone uses
  as it is.
- The app is React Native with Expo SDK 58 and TypeScript. A scan in Phase 9 found **no**
  `Platform.OS` branch and no Android-only module in `apps/mobile/src`.
- Every native dependency supports iOS: MapLibre React Native, `expo-file-system`,
  `expo-secure-store`, `expo-sqlite`, `expo-sharing`, `react-native-svg`,
  `react-native-safe-area-context`. `fflate` is plain JavaScript (KPI "Android-only native
  dependencies: 0", met).
- The native projects are generated by `expo prebuild` and never committed or edited (CLAUDE.md), so
  `npx expo prebuild --platform ios` makes the Xcode project.

## 2. What is Android-specific today

| Item | iOS counterpart to decide in Phase 11 |
|---|---|
| `app.json` `android` block: package name, adaptive icon, `blockedPermissions`, `allowBackup: false`, the `.detour` intent filter | An `ios` block: `bundleIdentifier`, icon, a document type for `.detour` (Info.plist through config), and backup exclusion for documents (iCloud backup of the app container is on by default on iOS) |
| `plugins/withReleaseSigning.js`, the debug-key fallback | Signing in Xcode with the owner's Apple ID (free) or a paid Developer Program account |
| `plugins/withCleartextTraffic.js` (E2E only) | Not needed on iOS for HTTPS |
| The "Android APK" workflow | No workflow: the build happens on the Mac |
| The E2E workflow (Android emulator) | Out of scope for Phase 11 unless the owner asks |

## 3. The Mac route, step by step (to be verified in Phase 11)

The facts marked ✗ are from ADR 008 and still unverified; Prompt 13 starts by reading Expo's and
Apple's current pages.

1. Install Xcode from the Mac App Store, and Node 22 (✗ Xcode version needed for SDK 58).
2. Clone the repository, `npm ci` at the root.
3. `cd apps/mobile && EXPO_PUBLIC_DETOUR_API_URL=https://<your-service>.onrender.com npx expo prebuild --platform ios`.
4. `npx expo run:ios --device --configuration Release` with the iPhone connected by cable and
   developer mode on (✗ exact steps). Compiling locally needs no Expo account and is "the only way to
   install a development build on an iPhone without a paid Apple Developer account" (Expo, read
   2026-11-12, ADR 008).
5. ✗ How long an app signed with a free Apple ID stays valid before it must be reinstalled, and how
   many apps it allows. If too short, the owner decides about the paid program ($99 a year).

## 4. To check on an iPhone in Phase 11

Permissions (none should be asked: no location, no photos; the file picker needs none), safe areas
and the notch on every screen, map rendering and its credit line, the share sheet and opening a
`.detour` file, Quick Look for documents, the keyboard over forms, dark mode (the design is light only),
and that the secure token store and the SQLite cache survive an app update.
